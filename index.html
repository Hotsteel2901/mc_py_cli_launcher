MC CLI Launcher

简洁的 Minecraft 命令行启动器 — Microsoft 登录、Fabric 模组加载器、Modrinth 模组管理

View on GitHub

功能特性

Microsoft OAuth2 登录

支持设备码流程，安全便捷地登录你的 Minecraft 账号

Fabric 模组加载器

一键安装 Fabric Loader，自动下载依赖库

Modrinth 模组管理

搜索、安装、更新模组，自动检测加载器类型

多线程下载

带进度条和 SHA-1 校验，断点续传，高效稳定
