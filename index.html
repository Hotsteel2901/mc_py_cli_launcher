Features
功能特性
Auth
浏览器登录
默认浏览器登录 Microsoft 账号，复制粘贴 URL 即可
Loader
Fabric / Forge / NeoForge
三种主流加载器可选安装，版本隔离，同一版本可装多个加载器并在启动时切换
Java
Java 自动匹配
按游戏版本要求自动选择本机 Java，缺失时自动下载 Mojang 官方运行时，不影响系统
Mods
Modrinth
搜索与安装模组，附带各加载器支持版本一览与依赖检测，无需 API Key
Search
精细搜索
search-more 按 slug 查看模组详情：加载器支持表、支持的 MC 版本、最近发布
Download
多线程下载
带进度条和 SHA-1 校验，断点续传，高效稳定
Download
下载

Getting Started
使用教程
mc_launcher
# 登录 Microsoft 账号（浏览器，默认） $ ./mc_launcher login # 或使用设备码登录（需要自备 Azure 应用） $ ./mc_launcher login --device-code # 安装模组加载器（Fabric / Forge / NeoForge） $ ./mc_launcher install-fabric -v 1.21.4 $ ./mc_launcher install-forge -v 1.20.1 $ ./mc_launcher install-neoforge -v 1.21.4 # 搜索模组（附各加载器支持的最高版本） $ ./mc_launcher search sodium $ ./mc_launcher search iris --limit 5 # 精细搜索：查看模组详情（需完整 slug） $ ./mc_launcher search-more sodium # 安装并启动 $ ./mc_launcher install-mod sodium -v 1.21.4 $ ./mc_launcher play -v 1.21.4 --fabric # 指定内存 / 窗口大小 / Java 路径（默认自动匹配并按需下载 Java） $ ./mc_launcher play -v 1.21.4 --ram 4G --width 1920 --height 1080 $ ./mc_launcher play -v 1.21.4 --java "C:\Program Files\Java\jdk-21\bin\javaw.exe"
